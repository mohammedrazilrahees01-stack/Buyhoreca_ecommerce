# Brand Logo Fix

Brand showcase now uses actual brand image assets from the BuyHoreca repository where available, with a remote GitHub asset fallback if the local asset is absent in a copied/deployed package. Existing Ziora, Vollrath, iSi, Eros and Eco-Botanics local assets remain unchanged. Pujadas uses a local SVG wordmark asset because no Pujadas image asset exists in the current repository tree.

The local-first mapping covers: Winco, Cambro, Carlisle, Mercer Culinary, San Jamar, Bunn, Knicer, Bisetti, Brewing Edge, Borgonova, Cooper Atkins, CutleryPro, Edhard, GI Metal, Kalando, Sonoco, Thermo Hauser, Tight Vac, BuyHoreca and Pujadas.
