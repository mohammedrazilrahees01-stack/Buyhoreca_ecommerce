# BuyHoreca UI V8 — Vertical Offer Panels

The hero offer area is now explicitly vertical on desktop/tablet and mobile: the WELCOME10 image offer sits above the HORECA5 image offer in the right-hand hero column.

Each offer remains a full clickable button; clicking anywhere on that offer copies its code to the clipboard and changes the control state to "Copied".

No other hero content was changed in this patch.
