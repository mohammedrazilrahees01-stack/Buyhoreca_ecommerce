# BuyHoreca Next — Initial Production Shell

Copy these files into the existing `C:\buyhoreca-next` project.

Your existing logo must remain at:
`public/images/buyhoreca_logo.png`

This shell intentionally contains no fabricated product catalogue, pricing, inventory, brands or checkout data. Those will be sourced from the real BuyHoreca Shopify catalogue in the integration phase.

After copying, run:
`npm run dev`

Then open:
`http://localhost:3000`
