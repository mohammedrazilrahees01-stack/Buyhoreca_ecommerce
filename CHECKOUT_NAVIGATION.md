BuyHoreca checkout navigation

The storefront cart now provides an explicit Home action before entering Shopify checkout.
The payment page itself is Shopify-hosted through Cart.checkoutUrl. A custom Home/Continue Shopping control inside hosted checkout is controlled by Shopify checkout settings/extensions, not by this storefront code. Shopify documents cart links and checkout extensibility; advanced checkout branding/navigation requires Checkout Extensibility and Shopify Plus where applicable.
