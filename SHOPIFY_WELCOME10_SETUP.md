# BuyHoreca first-order discount — WELCOME10

Use this configuration in Shopify:

- Discount type: **Amount off order**
- Code: **WELCOME10**
- Value: **10%**
- Minimum purchase: **No minimum requirements**
- Maximum discount uses: leave total-use limit **off**
- **Limit to one use per customer: ON**
- Schedule: no end date for an evergreen offer
- Combinations: leave disabled unless you intentionally want WELCOME10 to combine with another discount

The key setting for preventing a second redemption by the same customer is **Limit to one use per customer**. Shopify enforces that restriction for the discount code; the storefront does not need custom JavaScript for it.

For a campaign with a fixed closing date, use **Set end date** instead of leaving the discount evergreen.
