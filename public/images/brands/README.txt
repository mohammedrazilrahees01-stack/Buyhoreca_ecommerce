BuyHoreca brand logos

The Brands page has a dedicated logo slot for every known brand.

Current placeholder files are stored here as:
  <brand-slug>.png

Replace a placeholder PNG with the approved official logo using the same filename and the website will use it automatically.

Examples:
  bisetti.png
  cambro.png
  cooper-atkins.png
  mercer-culinary.png

BuyHoreca itself uses the existing official asset:
  /public/images/buyhoreca_logo.png

For a newly added Shopify brand, add its slug and logo path to BRAND_LOGOS in app/[[...slug]]/page.tsx.
